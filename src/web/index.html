Browse on your TV

Open Safari on this Mac, then display it on the TCL using AirPlay. This is not a browser installed on Roku, and the TV remote’s arrow buttons are not a browser mouse.

Checking Mac display sharing…
  1. Click Browse on TV. The app selects your verified TCL receiver using its actual AirPlay device ID, not the Roku display name. Enter the TV’s code on your Mac if prompted, then choose Mirror Entire Screen / screen mirroring rather than an extended desktop for the simplest setup.
  2. In Safari, press ⌘L to enter another URL or search. Use your Mac keyboard and trackpad normally to click, scroll, go back and play videos. Leave the address above blank to open an empty browser tab.
  3. Once sharing is active, Open Safari only opens another website without reopening the picker. To finish, use macOS Control Center → Screen Mirroring → Stop.

Full-screen mirroring shares visible Mac windows and notifications. Keep this Mac awake and connected. Some protected videos prohibit screen mirroring. This app reports Mac display topology; it cannot see the TV’s screen or detect every window-only sharing session.

Picture-setting scope and safety

The input, mode, values and choices above come from your TV. Each change checks the current context, writes a named setting, then reads it back. A stale input/mode is rejected instead of modifying a different profile. Refresh after changes made with another remote.

Settings are generally saved per input and picture mode. Selecting Custom color space uses the TV’s existing calibration; this remote does not edit white-balance tables or service-menu values.

CouchKeys for Mac

Open CouchKeys.app from Applications or its Desktop shortcut, then click the TV icon in the Mac menu bar. The native app connects directly to this TCL Roku TV and does not require this web server or a Terminal window. Allow Local Network access when macOS asks.

Verified controls include the actual volume slider and mute, native Roku Netflix/YouTube launching, inputs, and picture presets with TV readback. Numeric panel backlight is not exposed by the verified interface. Input names are labels reported by Roku, not proof of attached hardware.

Keyboard search: open Netflix Search on the TV, then type or paste into the native remote’s Keyboard field. Press Return or click Send to append that text to the focused TV field. Delete on TV sends Backspace; Enter on TV submits the TV field. Editing the Mac draft does not change text already sent. Text uses ordered, UTF-8-encoded Roku literal keys; the TV must have a text-entry screen open and the app must support keyboard input. The draft is consumed once, and failed or partial sends are never automatically replayed. The TV acknowledged text and Backspace during a native UI smoke run with Netflix active; Netflix’s on-screen text and results cannot be read back by this remote.

Fast TV Start was enabled with approval and its original OFF value is saved under device-backups/roku-fast-start-original-X01200UWX4Y2.json. It uses more standby power; no one-second cold-boot claim, root access, custom Roku Home replacement or system-package debloat is implied.

Local-only · no root, firmware changes or LG/webOS scripts. Close the remote’s Terminal window or press Ctrl+C there to stop the server. Relaunch using CouchKeys Web.command on your Desktop. This page runs on this Mac only.

Connection help & protocol details

Enable Settings → System → Advanced system settings → Control by mobile apps → Network access → Enabled. If the TV’s IP changes, run .venv/bin/python src/web/server.py --tv NEW_IP from the project directory. The remote remains locked to your TV’s serial number.

Power changes are verified against the TV’s reported screen state. This TCL ignored immediate reverse power commands during testing; the remote spaces power changes by 10 seconds, including a startup settling window. Navigation also waits out that window. Wake network separately sends a Wake-on-WLAN packet when standby prevents a connection. Deep-standby wake depends on the TV’s power/network configuration; a sent packet is not a confirmed power-on. Refresh after it wakes, then use Power on if the display remains off.

Picture and screen-on controls use authenticated Roku ECP2; navigation, sound, screen-off and app launching use documented HTTP ECP. Picture operations were recovered from the official Roku Android app and exercised against your TCL 65S451. No command is retried automatically after a connection failure.
